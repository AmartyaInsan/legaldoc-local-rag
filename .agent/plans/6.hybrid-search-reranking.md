# Plan 6: Hybrid Search & Reranking

**Complexity**: ⚠️ **Medium** (Sparse BM25 + Dense Vector + Reciprocal Rank Fusion + Cross-Scoring Reranker + Postgres FTS + UI Badges)

## Objective
Implement Module 6 according to PRD.md:
1. **Full-Text Keyword Search (Sparse Retrieval)**:
   - Add PostgreSQL Full-Text Search (`tsvector`, GIN index, and `plainto_tsquery`) in `supabase_schema.sql`.
   - Implement zero-dependency native BM25 sparse search (`BM25Searcher`) in Python for local memory and fast offline operation.
2. **Reciprocal Rank Fusion (RRF)**:
   - Combine dense vector similarity ranking and sparse keyword BM25 ranking using the standard RRF formula:
     $$RRF(d) = \sum_{m \in M} \frac{1}{60 + r_m(d)}$$
   - Track provenance (vector rank, keyword rank, scores).
3. **Reranking Step**:
   - Implement `backend/app/services/reranker.py`.
   - Re-score and re-rank the top RRF candidates based on query-document cross-alignment (term density, semantic coverage, title relevance).
   - Produce the final top $K$ excerpts with rerank confidence.
4. **Chat & UI Integration**:
   - Allow user to toggle between `Hybrid (Vector + BM25)`, `Vector Only`, and `Keyword Only` in `ChatInput.tsx`.
   - Display hybrid provenance badges (`[⚡ Hybrid: Vector #1 + Keyword #1] (RRF: 0.032 | Rerank: 94%)`) in `ChatMessage.tsx` citations.
   - Update `PROGRESS.md` upon completion.

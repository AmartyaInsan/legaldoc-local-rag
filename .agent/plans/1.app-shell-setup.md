# Plan 1: App Shell & Observability Setup (Enhanced Quality)

**Complexity**: ⚠️ **Medium** (Full-stack scaffold: Backend FastAPI + Frontend React/Vite + Supabase + Ollama/OpenAI config)

## Objective
Implement Module 1 with production-grade engineering and enhanced visual/technical quality:
1. **Local-First & Provider-Agnostic AI Engine**:
   - Out-of-the-box support for local **Ollama** (`qwen2.5:7b` for reasoning/chat + `nomic-embed-text` for vector embeddings).
   - Fully OpenAI-compatible architecture allowing seamless switching between Ollama, OpenRouter, and OpenAI via environment variables.
2. **Supabase Database & Authentication**:
   - Configured for Supabase Project (`your-project-id`).
   - SQL schema for conversations, threads, messages with Row-Level Security (RLS) policies.
3. **Backend Foundation (FastAPI + venv)**:
   - Modular architecture: `core/`, `api/`, `services/`, `schemas/`.
   - Streaming SSE chat endpoint with token metrics and LangSmith tracing support.
4. **Enhanced Frontend UI/UX**:
   - React + Vite + TypeScript + Tailwind CSS.
   - Polished dark aesthetic: glassmorphism, responsive sidebar for thread management, syntax-highlighted code blocks with copy button, animated live streaming cursor, and collapsible tool/reasoning cards.

---

## Tasks

### Task 1: Backend Foundation (FastAPI + venv)
- **Description**: Create `backend/` directory, set up `venv`, install dependencies (`fastapi`, `uvicorn`, `pydantic`, `pydantic-settings`, `openai`, `langsmith`, `supabase`, `python-dotenv`, `httpx`).
- **Configuration**:
  - `LLM_PROVIDER`: `ollama` (or `openai` / `openrouter`)
  - `LLM_BASE_URL`: `http://localhost:11434/v1`
  - `LLM_MODEL`: `qwen2.5:7b`
  - `EMBEDDING_MODEL`: `nomic-embed-text:latest`
  - `SUPABASE_URL`: `https://your-project-id.supabase.co`
- **Artifacts**: `backend/app/main.py`, `backend/app/core/config.py`, `backend/requirements.txt`, `backend/.env.example`
- **Validation**:
  - Run `uvicorn` and verify `http://127.0.0.1:8000/api/health` returns healthy status with Ollama connectivity verified.

### Task 2: Supabase Schema & Auth Middleware
- **Description**: Create migration SQL script for threads and messages tables with RLS and user isolation. Add JWT validation and Supabase client service in FastAPI.
- **Artifacts**: `backend/app/services/supabase.py`, `backend/app/api/deps.py`, `backend/supabase_schema.sql`
- **Validation**:
  - Test health check and verify database connection and schema validity.

### Task 3: Provider-Agnostic LLM Service & Streaming SSE
- **Description**: Implement asynchronous streaming chat completion service using standard OpenAI SDK pointed at `LLM_BASE_URL` (Ollama `qwen2.5:7b`). Support SSE streaming (`/api/chat/stream`) with optional LangSmith tracing.
- **Artifacts**: `backend/app/services/llm.py`, `backend/app/api/endpoints/chat.py`, `backend/app/schemas/chat.py`
- **Validation**:
  - Test streaming endpoint with `curl` or test script to verify tokens stream smoothly from Ollama `qwen2.5:7b`.

### Task 4: High-Quality Frontend Scaffold (Vite + React + TS + Tailwind)
- **Description**: Initialize `frontend/` using Vite with React and TypeScript, install Tailwind CSS, Lucide icons, clsx, tailwind-merge, and markdown renderers (`react-markdown`, `remark-gfm`).
- **Design Tokens**: Dark glassmorphic design system, subtle borders, glowing accent highlights, custom scrollbars.
- **Artifacts**: `frontend/package.json`, `frontend/vite.config.ts`, `frontend/src/index.css`, `frontend/src/App.tsx`
- **Validation**:
  - Verify clean build with `npm.cmd run build` and dev server launch.

### Task 5: Premium Chat UI & Thread Management
- **Description**: Build interactive chat workspace:
  - Sidebar: Thread list with active state, rename, delete, and new chat button.
  - Chat Area: Message list with user & assistant avatars, markdown parsing, syntax highlighting, copy button, animated streaming indicator, and provider badge (`qwen2.5:7b @ Ollama`).
  - Input Box: Auto-resizing textarea, keyboard shortcuts (`Enter` to submit, `Shift+Enter` for newline), stop generation button.
- **Artifacts**: `frontend/src/components/`, `frontend/src/hooks/useChat.ts`, `frontend/src/services/api.ts`
- **Validation**:
  - Verify live typing experience, streaming token animation, and thread persistence.

### Task 6: End-to-End Testing & Progress Tracking
- **Description**: Verify complete interaction loop from prompt submission to streaming completion in browser, document all settings, and update `PROGRESS.md`.
- **Validation**:
  - Check browser rendering, token streaming latency, and clean status update in `PROGRESS.md`.

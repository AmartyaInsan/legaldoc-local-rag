# Plan 9: 100% Local Close-Environment Database Migration (ChromaDB + SQLite)

**Complexity:** ⚠️ **Medium** - Replaces cloud Supabase with persistent local ChromaDB + SQLite and updates all learning notes to simple English.

## Goal
Migrate the RAG system from cloud Supabase (`pgvector`) to a **100% local, close-environment architecture** using:
1. **ChromaDB (`chromadb.PersistentClient`)** stored in `backend/local_data/chroma` for 768-dim vector embeddings (`nomic-embed-text`) and HNSW cosine similarity search.
2. **SQLite (`sqlite3`)** stored in `backend/local_data/legal_rag.db` for chat threads, message history, document metadata, SHA-256 deduplication (`record_manager`), BM25 keyword chunks, and the **Text-to-SQL** tool.
3. Update all code comments, learning notes, `README.md`, and `PROGRESS.md` to **simple, easy-to-understand English**.

## Tasks & Validation
1. **Local Database Service (`backend/app/services/local_db.py`)**
   - Implement `LocalDatabaseService` managing persistent SQLite (`legal_rag.db`) and persistent ChromaDB (`local_data/chroma`).
   - *Validation:* Verify tables and ChromaDB collection initialize automatically on import.
2. **Retrieval & Tools Migration (`retrieval.py`, `text_to_sql.py`, `chat.py`, `documents.py`, `health.py`)**
   - Point dense vector search to ChromaDB, BM25/metadata to SQLite, and Text-to-SQL to `local_db_service.conn`.
   - Remove legacy `supabase.py` and `supabase_schema.sql`.
   - *Validation:* Run an end-to-end Python test verifying document ingestion, vector + hybrid search, and cascade delete.
3. **Frontend & Documentation Updates**
   - Update UI badges (`Header.tsx`, `Sidebar.tsx`, `App.tsx`, `DocumentManager.tsx`) to display `ChromaDB + SQLite`.
   - Rewrite `README.md`, `PROGRESS.md`, and code learning notes in simple English.
   - *Validation:* Run `npm run build` in `frontend/` with zero TypeScript or bundler errors.

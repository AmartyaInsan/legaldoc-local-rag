# Plan 3: Record Manager & Multi-Format Ingestion (PDF & Word)

**Complexity**: ✅ **Simple** (Content Hashing + Deduplication + Incremental Ingestion + PDF/Word Support)

## Objective
Implement Module 3 (Record Manager) and multi-format document support (PDF and Word `.docx`):
1. **Multi-Format Extraction**:
   - Add parser for Adobe PDF (`.pdf`) using `pypdf` / fallback.
   - Add parser for Microsoft Word (`.docx`) with built-in standard library OpenXML extraction (`zipfile` + XML) and `python-docx` support.
2. **Content Hashing (SHA-256)**:
   - Compute cryptographic hash of raw uploaded file bytes.
3. **Deduplication**:
   - Detect if an exact duplicate document already exists in the vector database.
   - Skip redundant chunking and embedding generation if the file hash already exists, saving computation and avoiding duplicated search results.
4. **Incremental Ingestion (Update Mechanism)**:
   - If a file with the same filename is uploaded with modified content (hash differs), automatically delete stale chunks for that document and re-index with new chunks.
5. **Frontend UI Integration**:
   - Update file picker to accept `.pdf` and `.docx`.
   - Add visual badges for `Deduplicated`, `Updated`, and `Indexed`.
